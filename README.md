<h1>🚗 Car Lease Analyzer</h1>

AI-powered full-stack web application that analyzes car lease contracts and helps users understand whether a lease agreement is fair.

<h2>Features</h2>

📄 Upload lease documents (PDF / JPG / PNG)

🤖 AI extraction of lease terms using LLM

⚖️ Fairness score and red flag detection

📊 Comparison with estimated market lease prices

🚘 VIN lookup for vehicle details and recalls (NHTSA)

💬 AI negotiation assistant chatbot

<h3>Tech Stack</h3>

React • Vite • Node.js • Express • MongoDB
